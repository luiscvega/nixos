# NixOS Configuration

Single-user NixOS flake shared by two machines, `x13-gen2` and `x13-gen3`. Keep it minimal, simple, and straightforward.

## Structure

- `flake.nix` — Inputs and one `nixosSystem` entry per machine (hostname + `system.stateVersion`)
- `configuration.nix` — Shared system config (boot, networking, locale, desktop, audio, services, users, system)
- `home.nix` — Shared user config via home-manager
- `hardware-<host>.nix` — Per machine, auto-generated by `nixos-generate-config`, avoid manual edits

No `modules/`, `hosts/`, or `lib/` directories. Machines differ only in hardware, hostname, and `system.stateVersion` — don't over-abstract.

## Principles

- Minimal: don't add things that aren't needed
- No defaults: don't set options to their default values
- No dead code: no commented-out code, no stale comments, no unused args
- Best practices: firewall enabled, GC configured, store optimized, user packages in home-manager

## Style

- Format with `alejandra` before committing
- Function args: only list what's actually used (e.g. `{ pkgs, ... }:`)
- Inline single-attr blocks: `services.printing.enable = true;` not `services.printing = { enable = true; };`
- Group related multi-attr blocks: `services.tailscale = { enable = true; useRoutingFeatures = "client"; };`
- Section comments in `configuration.nix`: `# Boot`, `# Networking`, `# Locale`, `# Desktop`, `# Audio`, `# Services`, `# Users`, `# System`

## Packages

- System packages in `configuration.nix` `environment.systemPackages`, user packages in `home.nix` `home.packages`
- Prefer home-manager modules (`programs.X.enable`) over raw packages when available
- Set `enableBashIntegration = false` for Ghostty since it auto-injects shell integration

## Neovim

- coc.nvim for Go LSP (gopls)
- typescript-tools.nvim for TypeScript (standalone, does NOT use nvim-lspconfig)
- Don't mix coc and nvim-lspconfig for the same language

## Commands

```bash
sudo nixos-rebuild build    # Build without activating (verify config compiles)
sudo nixos-rebuild switch   # Build + activate + update bootloader (picks the host by hostname)
alejandra *.nix             # Format before committing
```

Adding a machine: `sudo nixos-generate-config --show-hardware-config > hardware-<host>.nix`, `git add` it (flakes only see tracked files), add a `nixosSystem` entry with the release it was installed with, then `sudo nixos-rebuild switch --flake .#<host>` once.
